# Chrono Glow

A modern and interactive clock UI built using HTML, CSS, and JavaScript.

This project combines:

* Analog Clock
* Digital Clock
* Live Date
* Dynamic Greetings
* Lottie Animations
* Glassmorphism Design

to create a clean and visually appealing real-time clock experience.

# Features

## Analog Clock

* Smooth rotating hour, minute, and second hands
* Stylish circular UI
* Inner and outer ring effects

## Digital Clock

* Live 12-hour format
* AM / PM support
* Leading zero formatting

## Dynamic Greeting System

Greeting changes automatically based on current time:

* Good Morning
* Good Afternoon
* Good Evening
* Good Night

## Lottie Animations

Animated illustrations change according to greeting and time of day.

## Responsive Design

Optimized for:

* Desktop
* Tablets
* Mobile devices
